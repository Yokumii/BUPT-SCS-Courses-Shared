# PM2.5数据集空值处理

## 项目说明

本项目用于分析处理 2015 年北京市 PM2.5 指数数据集空值。

## 数据文件

### 输入文件
- `data/BeijingPM20100101_20151231.csv` - 原始数据集（2010-2015年）

### 输出文件
- `data/processed/Beijing_PM2.5_2015_raw.csv` - 2015年原始数据（含空值）
- `data/processed/Beijing_PM2.5_2015_processed.csv` - 2015年处理后数据（已处理空值）

## 空值处理方法

### 1. PM2.5浓度数据（4列）
- **列名**：PM_Dongsi, PM_Dongsihuan, PM_Nongzhanguan, PM_US Post
- **方法**：线性插值（`interpolate(method='linear')`）
- **理由**：PM2.5浓度在时间序列上具有连续性，相邻时刻的浓度变化平滑

### 2. 气象数据（5列）
- **列名**：DEWP（露点）, TEMP（温度）, HUMI（湿度）, PRES（气压）, Iws（风速）
- **方法**：线性插值（`interpolate(method='linear')`）
- **理由**：气象要素在短时间内变化平滑，适合使用插值法填补

### 3. 风向数据（1列）
- **列名**：cbwd（组合风向）
- **方法**：前向填充（`ffill()`）+ 后向填充（`bfill()`）
- **理由**：风向为分类变量，不适合插值；短时间内风向变化较小，使用前一时刻风向较为合理

### 4. 降水量数据（2列）
- **列名**：precipitation（小时降水量）, Iprec（累计降水量）
- **方法**：填充为0
- **理由**：数据集中空值代表该时段无降水记录，填充为0符合实际意义
